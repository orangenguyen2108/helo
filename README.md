# ✍️ IELTS Writing Coach

Web app hỗ trợ luyện IELTS Writing dùng Claude AI.

## Tính năng
- 🎯 Chấm điểm 4 tiêu chí IELTS (Task Achievement, Coherence, Lexical, Grammar)
- ❌ Phát hiện và sửa lỗi ngữ pháp
- 📈 Gợi ý từ vựng nâng band
- 📖 Tạo sample answer Band 8-9
- 🏗️ Phân tích cấu trúc bài
- 📚 Từ vựng & cấu trúc theo chủ đề

## Cài đặt

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Dùng
1. Lấy API key tại https://console.anthropic.com
2. Nhập key vào sidebar
3. Chọn tab và bắt đầu luyện!
